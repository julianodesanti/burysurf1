Weekly wave forecast & historical phenomenological record of the Balneário Camboriú coastline (blog & vlog).

Newsletter signup is shown whenever index.php is opened. New signups are pending until the recipient opens the confirmation link and explicitly confirms within 48 hours. Only confirmed subscribers appear in the admin list and receive newsletters. In admin.php, use "Disparar newsletter" to compose and send a plain-text email to each confirmed subscriber, and "Inscritos" to view the confirmed email list.

After deploying newsletter database changes, log in to admin.php and select "Preparar/atualizar banco da newsletter" in the Inscritos tab. This creates or updates the subscriber table, repairs zero/invalid created_at values using the migration time, fills unique 32-character unsub_token values, and marks legacy subscribers as confirmed so their existing subscriptions continue to work. An invalid legacy date cannot be recovered, so its replacement is the migration date. New subscription dates are explicitly saved in YYYY-MM-DD HH:MM:SS format using the America/Sao_Paulo timezone. Confirmation tokens are stored as hashes and expire after 48 hours.

Newsletter delivery uses PHP's mail() function. The server must have mail delivery configured. NEWSLETTER_FROM_EMAIL can be set in the PHP environment; the default sender is contato@burysurf.com.
